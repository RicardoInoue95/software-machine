# 01 — Ideias Brutas

Aqui entra **tudo** que o CEO trouxer: um estalo, uma frase, um print, uma referência. Sem filtro de qualidade — o filtro acontece na maturação.

## Regras

- Uma ideia = um arquivo `<slug>.md`, criado a partir de `_FICHA-TEMPLATE.md`.
- A ficha pode ficar incompleta. O mínimo obrigatório é: **slug, tipo, uma frase que descreva a ideia**.
- O Diretor Geral, ao registrar a ficha, já anexa as **3 a 5 perguntas** que precisam ser respondidas para a ideia avançar.
- Ideias que ficarem aqui por mais de 90 dias sem movimento recebem `status: arquivada` (não são apagadas).

## Para avançar

Quando o CEO decidir lapidar uma ideia, o Diretor cria a pasta `../02-maturacao/<slug>/`, move a ficha para lá como `00-ficha.md` e aplica o molde de incubação correspondente (`_templates/incubacao-jogo.md` ou `_templates/incubacao-software.md`).
